# 管理画面のデザイン

2026-09-22に提供された「Cursor — Style Reference / Warm parchment atelier lit by embers」を、個人ブログの管理画面へ適用する規範。公開サイト用の `docs/design-system.md` とは別のデザインである。

## 適用範囲

`/authoring/articles`、`/authoring/webmentions`、`/draft-editor` の操作UIに適用する。公開サイト、公開記事、draft-editor内の公開プレビューは対象外。CSS変数は管理画面の要素にスコープし、`:root` の公開テーマを書き換えない。

## 見た目

温かい紙面とInkの文字、薄い境界線を基本とする。ライトテーマ固定。面はフラットに保ち、影はメニュー・ダイアログの重なりに限る。大きな装飾、グラデーション、発光は使わない。

### 色

| 名前 | 値 | 用途 |
| --- | --- | --- |
| Parchment | `#f7f7f4` | 基本の紙面 |
| Bone | `#f2f1ed` | サイドバー、補助面 |
| Linen | `#e6e5e0` | ホバー、補助操作 |
| Stone | `#cdcdc9` | 区切り線 |
| Mist | `#a1a19f` | 非アクティブな装飾 |
| Driftwood | `#84847e` | 補助的な図形 |
| Ash | `#7a7974` | アイコン、下書きの印 |
| Ink | `#26251e` | 本文、見出し、主操作の背景 |
| Ember | `#f54e00` | 短い強調。背景や主操作には使わない |
| Amber | `#c08532` | 未公開の変更、送信待ちの印 |
| Forest | `#34785c` | 選択中のナビゲーション、公開済みの印 |
| Verdant | `#1f8a65` | 補助アクセント |
| Crimson | `#cf2d56` | 要確認・失敗の印と文字 |

状態を色で判別したいという依頼に合わせ、参考資料の「緑を状態色にしない」よりも上記の状態マッピングを優先する。状態名も必ず併記する。Amberなど明るい色は小さい文字に直接使わず、色の印とInkの文字で示す。補助文字はAshとInkを混ぜてコントラストを確保する。意味を持つ色は `--authoring-*` の用途別トークンから参照する。

### 文字

- UI・見出し: CursorGothic、代替はInter / Helvetica Neue / 日本語ゴシック。未提供の商用フォントは取得しない。
- 日時・URL・コード: berkeleyMono、代替はSFMono-Regular / Menlo / monospace。数値はtabular-nums。
- EB Garamond / Iowan Old Style / Georgiaは編集的な長文用。ナビや小さな表のラベルには持ち込まない。
- 見出しは400。管理画面見出し26px / 行高1.25 / 字間-0.012em、補助見出し22px / 1.3 / -0.005em。
- UIは14–16px、補助情報12–13px。日本語の長いタイトルは折り返し、全体を読めるようにする。
- 大きい見出しが必要な場合のみ36px / 1.2 / -0.02em、72px / 1.1 / -0.03em。管理一覧にheroは置かない。

### 余白と形

4pxを基準に、4 / 8 / 12 / 16 / 20 / 24 / 32 / 48 / 56 / 64pxを使う。ボタン・入力・カードは4px角丸、モーダルは8px。提供資料末尾の白文字・pillボタンの例より、この規則とParchment文字を優先する。primaryはInk背景、secondaryはLinen、ghostは透明。主操作を同列に複数強調しない。

## 記事一覧

最大1300pxの一覧に24pxの余白。デスクトップは約224pxのサイドバーでアイコンとラベルを横並びにする。記事を書く主操作、記事一覧、Webmention、公開サイト、日記への既存導線を残す。スマートフォンではナビを横並びに再配置して本文幅を確保する。

```text
サイドバー       記事の管理
記事を書く       検索                         再読み込み
記事一覧         すべて / 下書き / 未公開の変更あり / 公開中 / 要確認
Webmention       記事・状態       …  Webmention   投稿日   最終更新日  開く
公開サイト       タイトル        …       2       日時     日時        ↗
日記を書く       公開中・保存済み
```

各行へ公開状態・端末未送信・公開処理の失敗をまとめる。右の選択詳細ペインは置かない。公開処理の詳細は行内の開閉で見られるようにし、復旧操作を失わない。

- タイトルは編集へのリンク。
- 三点メニューは編集と、必要時の公開処理再試行。未実装の複製・履歴・削除・固定表示を見せない。
- Webmention数は検証済みかつ承認済みで、公開用スナップショットのある受信件数。0と取得不能は区別する。
- 投稿日は初回公開日時。下書きは「未公開」。最終更新日はサーバーへ保存した日時。端末未送信は別途明示する。
- 公開済み行だけ、公開記事を別タブで開くアイコンリンクを出す。
- 狭い画面では行を縦に組み直し、列名を併記する。横スクロール前提にしない。

## エディタ

狭いサイドバーと既存の本文・素材欄レイアウトを維持する。紙面・ツールバー・ダイアログ・保存状態へ管理画面の色を適用する。公開プレビューの見た目とテーマは維持する。

## アイコンと操作

Regen Iconsを使い、出典と `regen-icons-LICENSE.txt` を保持する。24pxグリッド、currentColor、同じ線幅を使う。アイコンだけの操作には名前を付ける。

メニューはEnter・Space・矢印で開き、矢印で移動、Escapeで閉じて元のボタンへフォーカスを戻す。外側クリックでも閉じる。フォーカスを可視化し、色だけを頼りにしない。ポインタ領域はデスクトップ40px、タッチ44pxを目安にする。

## 確認

一覧の通常・検索・空・ページ追加・端末未送信・要確認、三点メニューのキーボード操作、320px幅・200%相当の幅、編集画面と公開プレビューの分離を確認する。公開サイトのテーマ値と表示を変更しない。
