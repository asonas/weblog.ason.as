# ユニバースの固定グラフ

## 表示と操作

本文下の中央を表示中の記事の起点とし、本文のリンク先を左、被リンク元を中央、曜日・日付・日記のノードを右に配置する。被リンク元は名前付きノードと点線で区別する。本文中の語句への線、矢印、ドラッグ、拡大縮小の操作は設けない。

名前付きノードの先にある点は、既存の関連APIで読み込んだ記事を表す。全サイトのリンクを再帰取得したグラフではない。「続きを読み込む」で関連APIの次のページを取得する。被リンクは `related_by` に現在の記事のrouteを含む記事から抽出し、API・データモデルの変更は行わない。

記事ノードは接続数が多いほど大きく、作成日時が新しいほど濃く、古いほど薄くする。既存の計算式を引き継ぎ、直径は14〜26、透明度は0.35〜1の範囲とする。作成日時不明の場合は濃く表示する。

ポインタは画面座標で最も近い点を判定する。常時表示するラベルだけを補助的な判定対象とし、ホバー中に現れるラベルで判定領域を変えない。キーボードではノードをフォーカスしEnterまたはSpaceで詳細へ移動できる。Escapeで詳細を閉じ、起点のノードへフォーカスを戻す。

詳細はカード外のクリック・タップで閉じる。画像がある場合だけ、画像上に開く・閉じるアイコンを表示する。画像は左右余白なし。外部リンクは選択時に既存embed APIからOGPを取得し、失敗・タイムアウトでも元のURLを開ける状態を保つ。画像の読み込みに失敗した場合は画像なしカードに切り替える。

700px以下では話題・リンク元・日付を切り替える。小さな点の精密なタップを要求せず、名前付きノードの詳細から関連記事へのリンクを辿れる。グラフの文字サイズは画面幅と一緒に縮小しない。既存のユニバース表示設定がオフの場合は関連する記事の一覧を使う。

## 検証

`mise exec -- npm run lint:authoring`、`mise exec -- npm run typecheck`、`mise exec -- npm run test:authoring`、`mise exec -- npm run build` を使用する。

実コンポーネントのテストでは被リンク、ノードの濃淡・サイズ、拡大された画面座標でのヒット判定、画像あり／なしのカード、画像・OGP取得失敗、外側クリック、キーボードのフォーカス復帰、狭い画面の代替操作を確認する。エディタの入力・閲覧・ユニバース無効時の既存テストも維持する。

Firefoxの通常URLで `/2026-09-06` と「weblog.ason.asの書き心地」の関係、外部リンクのOGP表示、320px幅の切り替え・カード表示を確認した。スマートフォン実機、Safari、初見利用者による関係の判別性は未確認。
