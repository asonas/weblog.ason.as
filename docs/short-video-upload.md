# 短い動画のアップロード

エディタへのドロップ・貼り付けから動画を追加する。
アップロード完了後、AV1とH.264を1つの動画素材として登録する。
インボックスの「動画」列からクリックして再利用できる。
本文から削除しても素材とファイルは残り、再挿入時に変換・アップロードは行わない。
動画素材には写真インボックスの有効期限や使用済み処理を適用しない。
この登録処理を導入する前にアップロードした動画は、自動では素材一覧に追加されない。

素材情報は `video_materials` テーブルに保存する。開発環境の起動と本番のDSQL bootstrapで作成する。
本番の導入時は、API更新前にTerraformの動画読み取り権限を適用し、DSQL bootstrapを実行する。
既存の認証・CSRF検証付き `POST /api/uploads` の `action: register_video` でMP4の存在を確認して登録し、`GET /api/inbox` で取得する。
エディタ上部に変換・送信の進捗とキャンセルボタンを表示する。
処理中は本文入力と公開を停止し、完了した動画を開始時の選択位置へ挿入する。
別端末の編集やかけらの切り替えで本文が変わった場合は挿入せず、登録済みの動画はインボックスから追加できる。
ページを離れたときは処理を中断する。失敗時は理由を表示し、再度ドロップ・貼り付けしてやり直せる。
ブラウザ内の専用Workerで最大1080p相当・30fpsのMP4を生成し、既存の認証付き `POST /api/uploads` が発行した署名付きPOSTでS3へ送信する。
配信URLは既存のCloudFrontを通る `/assets/uploads/YYYY/MM/UUID.mp4`。
MediaConvertや新しいAWSリソースは使わない。

## 変換

- 入力は500MB以下、60秒以下のSDR。HDRやデコード非対応の入力は理由を表示して停止する。
- H.264（映像4.5Mbps）を生成し、AV1生成対応の端末ではAV1（2.3Mbps）も生成する。
- 元動画をアップロードしない。映像は縦横比を保って縮小し、拡大しない。
- AAC音声はコピーし、他の対応音声はAACに変換する。音声の脱落を許さない。
- 出力は各50MiB以下。サーバーの署名付きPOSTも同じ上限と `video/mp4` を強制する。
- キャンセルはWorkerと送信を中断する。すでに送信を完了したファイルは残る（既存画像と同様、自動削除はしない）。
- 画像と動画の混在ドロップは、分けて操作するよう案内する。

## 保存と再生

新規アップロードとインボックスからの挿入は `[動画名](/assets/uploads/YYYY/MM/UUID.mp4)` の通常のMarkdownリンクを使う。
リンク先はH.264版。AV1版と寸法は素材情報に保持する。プレビューと公開ページではリンクをクリックして動画を開く。
本文は、変換・すべての出力ファイルの送信・素材登録が成功してから変更する。失敗・キャンセル時はリンクを追加しない。
既存の `:::video H264のパス AV1のパス 1920x1080 :::` は維持し、従来どおり本文内のプレイヤーとして表示する。
本文のリンクや動画記法を削除しても、素材とファイルは残る。
